Welcome to the public repository for **Temporal Loop Games**, an independent studio dedicated to building high-performance, zero-install 3D browser games.

## 🚀 Our Mission
We believe the future of indie gaming lies at the edge. We are developing lightweight, experimental 3D web experiences designed to run instantly in modern browsers without massive downloads or app store friction. 

By leveraging raw WebGL, custom JavaScript rendering pipelines, and global edge networks (Cloudflare), we aim to deliver low-latency gameplay globally.

## 🧠 AI-Driven Development
We are aggressively integrating LLMs into our production pipeline. We utilize **Anthropic's Claude** to:
* Architect and optimize complex WebGL rendering pipelines and GLSL shaders.
* Generate procedural puzzle mechanics and dynamic time-loop logic.
* Script adaptive NPC dialogue and real-time game state management.

## 🎮 Current Prototypes

Our current experimental showcase includes:
* **Chrono-Bot Maze:** A low-poly, isometric puzzle crawler focusing on geometric pathfinding.
* **Cosmic Orbit Racers:** A fast-paced orbital physics racer utilizing gravitational mechanics.
* **Time Loop Paradox:** A stylized retro-3D puzzle game built around manipulating spatial perspective.

## 🛠️ Architecture Overview
* **Frontend:** Vanilla JavaScript, HTML5 Canvas, WebGL 2.0
* **Deployment:** Cloudflare Workers / Pages for zero-latency edge delivery
* **Asset Pipeline:** Procedural generation backed by AI logic scripting

*Note: The core engine source code and proprietary game logic are currently maintained in private submodules. This public repository serves as the deployment source for our studio showcase and documentation.*
